# Screen previews

The PNG files are documentation previews rendered from the app's screen markup and stylesheet with the sample content shown in the project. They illustrate the dashboard, task manager, subject list, and progress tracker; use the live app for interaction and responsive behaviour.

- `dashboard.png` — overview and daily focus
- `tasks.png` — task list, filters, due dates, and completion states
- `subjects.png` — subject cards and completion indicators
- `progress.png` — overall and subject-level progress
