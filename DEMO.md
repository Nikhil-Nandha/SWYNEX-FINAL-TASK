# StudySprint — short demo note

## Demo duration

Approximately 60–90 seconds.

## Suggested walkthrough

1. **Dashboard (10 seconds):** introduce the overview cards, today's tasks, and subject progress.
2. **Subjects (10 seconds):** add a subject and point out that duplicate subject names are rejected.
3. **Create a task (20 seconds):** open Task manager, create a task with a title, subject, and due date, and show it in the list.
4. **Task actions (15 seconds):** filter tasks, mark the new task complete, and show the updated completion statistics.
5. **Progress (10 seconds):** open Progress tracker and show the overall and subject-level completion values.
6. **Persistence (10 seconds):** refresh the page and show that the task and subject remain available.

## Key result

A student can complete the main planning workflow—create a subject, create a task, manage its status, and review progress—without a backend. The app validates input, provides empty states and feedback, and saves user-created data locally in the browser.

## Demo narration

“StudySprint is a responsive student study planner built with HTML, CSS, and JavaScript. Students can organise subjects, create and manage study tasks, and track completion. Form validation prevents incomplete or invalid entries, while browser local storage keeps the student's data available after a refresh. The dashboard and progress screen update as tasks are completed.”

## Recording suggestion

Record the walkthrough at a desktop browser size first, then briefly show the mobile layout using the browser's responsive device toolbar. Use a fresh browser profile or clear the app's local storage before recording if you want the sample data to appear exactly as shown in the repository screenshots.
